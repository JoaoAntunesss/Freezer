# Freezer

App Android para gerir a arca congeladora: stock com validades, gastos, lista de compras, leitor de códigos de barras e IA para registar artigos por voz ou pela foto do talão. Os dados ficam guardados no Firebase.

## Descarregar

A versão mais recente está em [Releases](https://github.com/JoaoAntunesss/Freezer/releases/latest): descarrega o `freezer.apk` e instala-o (o Android pede para autorizar a instalação a partir dessa origem). As versões seguintes instalam-se por cima, sem perder dados, e a própria app avisa quando há uma nova.

Requer Android 7 ou superior.

## Compilar

O GitHub Actions compila e publica o APK automaticamente a cada push no `main`. Os passos e os segredos necessários estão em [NOTAS.md](NOTAS.md).
